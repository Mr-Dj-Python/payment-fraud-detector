FILE NO. 001 Built & Tested

Stopping a Real-Time Fraud Ring Without Slowing Down Payments

A payment platform's fraud model checks each transaction in about two seconds. An attacker splits ₹18 crore across roughly 10,000 mule accounts, in transfers too small and too normal-looking for that model to catch. This case builds the system that catches the pattern instead — without adding a measurable delay to a single real payment.
